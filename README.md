# Strela

A fast, modern and lightweight file manager for Android, designed for instant access to your newest files, full root control and seamless work with network and cloud storage.

## Key Features:

* **Instant Recent Files:** The home screen shows new files from Downloads (including subfolders), DCIM, Pictures, Telegram and other frequently updated folders. Thanks to the system media index, the scan completes in well under a second.
* **Full Root Access:** With Magisk, KernelSU or APatch, Strela shows absolutely every file on the device — including `/`, `/data`, `/system` and `Android/data` — with read, write and permission (chmod) support.
* **Built-in Text Editor:** Opens text files instantly. Line numbers, undo/redo, find & replace, go to line, automatic encoding detection (UTF-8, Windows-1251 and more), plus a fast viewer for huge logs of any size.
* **Network & Cloud:** FTP/FTPS client, WebDAV clouds (Yandex Disk, Mail.ru Cloud, pCloud, Koofr, 4shared, Nextcloud/ownCloud) and a built-in FTP server to access phone files from your PC over Wi-Fi.
* **Storage Devices:** SD cards and USB OTG drives, direct NTFS reading without root, and formatting to FAT32 / exFAT / NTFS / ext4 / F2FS with a custom volume label (root).
* **Everything Else You Need:** ZIP compression and extraction, Recycle Bin (30 days), storage analyzer, large file finder, app manager with APK backup, image viewer with zoom and EXIF info.
* **Clean, Customizable UI:** No ads, no trackers. 4 themes (including pure-black AMOLED), 6 accent colors, adjustable font size and 8 interface languages: English, Русский, Français, Deutsch, 中文, 한국어, Türkçe, العربية.

## How to Download & Install:

1. Go to the **Releases** section on the right side of the repository.
2. Download the latest `.apk` file.
3. Open it and install. (Note: Android may ask you to allow installing apps from this source, and Google Play Protect may show a warning on first install — tap "More details" → "Install anyway", as this is an independent developer build.)
4. On first launch, grant **"All files access"** so Strela can show and manage your files.

**Root users (Magisk 31.1 and newer):** the root request pop-up was removed in Magisk itself, so access must be granted in advance: open Magisk → **Superuser** → **"+"** → tick Strela. On Xiaomi / HyperOS, if Magisk's list shows only "Shell", allow Magisk the "Display installed apps list" permission first.

**Requirements:** Android 8.0 or newer.
